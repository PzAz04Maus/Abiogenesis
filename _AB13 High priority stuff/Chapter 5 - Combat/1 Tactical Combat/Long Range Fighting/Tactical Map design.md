# Current map types

There have been 2 devised types of maps so far. Each type is designed for different requirements.

## Type 1: Nodemap

pros:
- extremely easy to create
- ideal for long range combat
cons:
- harder to visualize; more abstract without a back topo layer or some other kind of background map
- harder to do areas or volumes of interest
- land features harder to turn into POIs (some patches or forms are only circumstantially important)

## Type 2: Heightmap

The heightmap is a simplification of a topography map, designed to model the underlying landforms of the terrain.

pros:
- useful for small battles, can be used for larger tactical engagements
- tight control over the battlefield's shape
- easy to visualize
- doesn't need conversion into a topography map
- simple to begin, easy to draw
- Details are emergent
- easy to extend
- 
cons:
- no dedicated software
- hard to convert into a high detail topography map (You need to tab all the elevations)
